# Shop bill Management System

This project is a simple billing application built with Python. I created it as part of a college assignment.  
It helps shopkeepers quickly generate bills by entering items, quantities, and prices.

 # Features
1. Add as many items as needed  
2. Each item includes a name, quantity, and unit price  
3. Calculates subtotal for each item and a grand total for the bill  
4. Automatically saves every bill in the *bills* folder  
5. Bills are stored with the current date and time, ensuring each file is unique
