# Project Statement – Shop Management System (Python)

# Problem Statement
In many small shops, bills are still written on paper and totals are calculated manually.  
Because of this, small mistakes happen and it also takes extra time.  
To solve this, I created a basic Python program which helps in generating a bill quickly by entering items, quantities and prices.  
The program also saves the bill into a text file so the shopkeeper can check it later whenever needed.


# Scope of the Project

#  What is included
1. Asking the user how many items they want to enter  
2.Taking item name, quantity and price  
3. Auto–calculation of total amount  
4. Displaying bill in a clear format  
5. Creating a *bills* folder automatically  
6. Saving each bill with a unique timestamp

# What is not included
1. No GST or tax calculation  
2. No discount features  
3. No database or inventory system  
4. No graphical user interface (command line only)  
5. Not suitable for big shop management



# Target Users
1. Small shop owners who want a simple quick billing solution  
2. Students who are learning Python basics  
3. Anyone who wants to practice file handling and loops in Python



# High Level Features
1. Simple and easy input system  
2. Input validation for quantity and price  
3. Neatly formatted bill output  
4. Automatic creation of bill text file  
5. Code is fully beginner–friendly and easy to understand

---

## Purpose of the Project
The main aim of this project is to practice Python programming concepts like loops, condition checking, functions, and file handling while building something meaningful and useful in real life.
